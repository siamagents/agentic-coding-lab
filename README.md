# Agentic Coding Lab · ระบบจองคิวร้านเล็ก

โปรเจกต์ตัวอย่างสำหรับคอร์ส **Agentic Coding ใช้งานจริง ด้วย Claude Code** ที่ [learn.siamagents.com](https://learn.siamagents.com)

เป็นโปรเจกต์เดียวกับที่ใช้อัดวิดีโอทุกตอน: ระบบจองคิวของร้านเล็ก ๆ มีหน้ารายการคิว (`src/queue-list.ts`) และไฟล์ส่งออก CSV ที่ร้านนำเข้าเครื่องขายหน้าร้านทุกเย็น (`src/export-csv.ts`) โค้ดตั้งใจให้สั้นและ **มีบักซ่อนอยู่** ไว้ให้ฝึก

## สิ่งที่ต้องมี

- Node.js 20 ขึ้นไป
- git
- [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) ที่ login แล้ว (ต้องมีแพ็กเกจ Claude Pro, Max หรือ API key)

## เริ่มต้น

1. กด **Use this template → Create a new repository** ที่หน้านี้ ตั้งเป็น **Public** จะได้ repo ของคุณเอง
2. clone repo ของคุณแล้วติดตั้ง:

```bash
git clone https://github.com/<ชื่อบัญชีคุณ>/agentic-coding-lab.git
cd agentic-coding-lab
npm install
npm test        # ต้องผ่าน 1 เทสต์
claude          # เปิด Claude Code ในโฟลเดอร์นี้
```

3. สร้างไฟล์ `.siamagents` ที่ root ใส่รหัสยืนยันที่แสดงในหน้าแล็บบน learn.siamagents.com แล้วคอมมิต เพื่อยืนยันว่า repo นี้เป็นของคุณ

## แล็บในคอร์ส

| แล็บ | ฝึกเรื่อง | อยู่หลังตอน |
| --- | --- | --- |
| แล็บ 1 | สั่งงานแรก, `/init` + กฎของทีม, เขียนคำสั่งให้จบในรอบเดียว | 1–3 |
| แล็บ 2 | อ่าน diff, ล็อกด้วยเทสต์, แก้บักแบบให้เกิดซ้ำก่อน, กัน `.env`, ถอยด้วย git | 4–8 |
| แล็บ 3 | โหมดวางแผน, ให้เอเจ้นท์รีวิว branch `lab/team-review` | 9–10 |
| โจทย์ปิดคอร์ส | ระบบยกเลิกคิว ทำครบทุกขั้น | 11 |

แต่ละแล็บมีเทสต์ตรวจงานใน `labs/` ซึ่ง **ล้มตั้งแต่แรก** หน้าที่ของคุณคือใช้ Claude Code ทำงานจนเทสต์ผ่าน ลองรันในเครื่องได้:

```bash
npm run lab:1       # แล็บ 1
npm run lab:2       # แล็บ 2
npm run lab:final   # โจทย์ปิดคอร์ส
```

แล็บ 3 ไม่มีเทสต์ เป็นการอ่านแผนและอ่านรีวิว ขั้นตอนละเอียดของทุกแล็บอยู่ในบทเรียนบนเว็บ

## ส่งตรวจ

ทุกครั้งที่ push ขึ้น GitHub ระบบ GitHub Actions (`lab-check`) จะรันเทสต์ทุกแล็บให้ ดูผลได้ในแท็บ **Actions** ของ repo คุณ จากนั้นไปที่หน้าแล็บบน learn.siamagents.com วางลิงก์ repo แล้วกด **ตรวจงาน** แล็บที่ผ่านจะถูกติ๊กว่าเรียนจบ ต้องผ่านครบทุกแล็บจึงจะรับใบรับรองได้

> GitHub Actions ใช้เทสต์ตัวจริงจาก repo ต้นแบบเสมอ แก้ไฟล์ใน `labs/` จึงไม่ช่วยให้ผ่าน และห้ามแก้ `.github/workflows/lab-check.yml` ไม่เช่นนั้นเว็บจะไม่รับผลตรวจ

## branch ในโปรเจกต์นี้

- `main` จุดเริ่มต้นของทุกแล็บ
- `lab/team-review` มีคอมมิตเพิ่มเบอร์โทรในไฟล์ส่งออก ไว้ฝึกให้เอเจ้นท์รีวิว (แล็บ 3) อย่ารวมเข้า `main`

ทำแล็บพังไม่ต้องกลัว เริ่มใหม่ได้ด้วย `git switch main && git reset --hard origin/main`
